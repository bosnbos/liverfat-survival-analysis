# Liver Fat and Chemotherapy Toxicity

Analysis of association between liver fat (HU) and treatment-limiting toxicity in CAPOX chemotherapy.

## Structure

data/        – dataset (not included in repo)
scripts/     – analysis code
docs/        – study documentation
output/      – generated reports

## Running the analysis

1. Place Dataset_liverfat.RData in `data/`
2. Open `liverfat_survival_analysis.Rproj`
3. Knit `liverfat_survival_analysis.Rmd`
